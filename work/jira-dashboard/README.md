# CPS Sprint Pulse

A platform-neutral, static Jira dashboard prototype using fictional sample data.
It shows the current two-week sprint and five earlier sprints, with story-point
and issue completion, a burndown chart, blockers, and scope changes.

## Preview

Open `index.html` in a browser. The prototype has no build step, external
packages, network requests, or Jira credentials.

Use the sprint selector to switch between the current sprint and five completed
sprints. The issue tables and metrics update with the selected sprint. The
sample current sprint is dated October 12–25, 2026.

## Demo limitations

All project and sprint data is illustrative. This page does not connect to Jira
and is not yet packaged as a Jira gadget. Jira Cloud and Server/Data Center
require different integration choices; confirm the CPS Jira platform before
adding a live connection or gadget packaging.
